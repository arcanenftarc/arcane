# Backgrounds

- `home.png` — About-section still (behind the framed collection art).
- `site.png` — Full-page backdrop behind the whole site, shown at low opacity.

Drop your site-wide image here as:

```
public/assets/background/site.png
```

Wide art (around 1920×1080 or larger) works best. The site covers the viewport and keeps it faint so text and collection frames stay readable.

The path is `siteConfig.assets.siteBackground` in `src/config/site.ts`.
