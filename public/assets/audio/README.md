# Audio

Drop your loop here. Clicks are synthesized on the site — you do not need a click file.

```
public/assets/audio/
  music.mp3   (preferred)
  music.ogg
  music.wav
  music.m4a
```

Use one of those exact names. The site looks for them in that order, then loops the first file it finds after the visitor taps once (browsers block autoplay until then).

A diamond control in the header mutes both the music and the click.
