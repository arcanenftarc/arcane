# Collection borders

Drop your custom frame PNG here:

```
public/assets/borders/collection-frame.png
```

Use a PNG with a **transparent center** so the collection art shows through. Square artwork (or a 1:1 frame) works best — the site stretches this file over every carousel slide and the About image.

The path is set in `src/config/site.ts` as `siteConfig.assets.collectionBorder`. Rename the file only if you also update that path.
